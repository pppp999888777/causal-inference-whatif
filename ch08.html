选择偏倚

只分析“被选进来”的那部分人，就是在条件化一个变量 C（被选中、没失访、有完整记录）。如果 C 是处理和结局（或它们的原因）的共同结果，条件化它就打开一条对撞路径，产生选择偏倚。即使处理是随机分配的，也躲不开。

和混杂的区别

混杂：共同原因，A ← L → Y。随机化能消除。

选择偏倚：条件化共同结果，A → C ← Y。随机化消除不了。

修正：IP 加权 WC = 1 / Pr[C=0 | A, L]
8.1–8.2

结构和常见的例子

最简单的结构：A → C ← Y。比如研究吸烟对心脏病的影响，只分析没有失访的人，而失访同时受吸烟和心脏病影响。更常见的是间接版本：A → L → C ← U → Y，处理让人出现某些症状 L，症状让人退出研究；同时某种没测量的体质 U 既让人退出，又影响结局。

书里列举的例子：

差异性失访（informative censoring）：失访和处理、结局都有关。缺失数据：只用完整记录的人。健康工人偏倚：只研究在职工人，而能继续工作本身就受健康影响。自愿者偏倚：愿意参加研究的人和不愿意的人不同。Berkson 偏倚：在医院里研究两种病的关系，住院是两种病的共同结果。

术语提醒经济学里的 selection bias 往往指“谁接受处理”带来的偏倚，在这本书的分类里那叫混杂。读别的文献时要分清是哪种结构。
实验台 1

随机试验里的失访

20000 人随机分组，处理对结局没有任何效应。处理让人出现副作用 L，L 让人退出；没测量的体质 U 让人更易退出，也更易出现坏结局。只分析没退出的人。

8.3–8.4

选择偏倚、混杂和删失

8.3 节：两种偏倚可能同时存在，结构不同，修正需要的变量也不同。修正混杂要测量 A 和 Y 的共同原因；修正选择偏倚要测量影响“被选中”的那些变量。

8.4 节：有删失时，我们真正想要的是“如果所有人都接受处理 a，而且没有人失访”时的结局，记作 Ya, c=0。也就是说，把“不失访”也当作一个处理，做联合干预。这样，选择偏倚就变成了“对处理 C 的混杂”，可以用同样的工具来处理。

8.5–8.6

怎么修正，以及什么时候选择不带来偏倚

书里的主要工具是删失的 IP 加权：每个没退出的人乘以 1 / Pr[C=0 | A, L]。退出概率高的那类人，留下来的每一位都要代表更多已经退出的同类。加权后的人群就像“没人退出”的人群。条件：给定 A 和 L，退出与潜在结局无关（对 C 的可交换性），以及每类人都有一定概率留下（正性）。

注意它只能修正经过测量了的 L 的那部分。实验台 1 里，退出还依赖没测量的 U，所以 IP 加权只能修正一部分。

8.6 节：选择不一定带来偏倚。随机抽样（比如从 EdNet 里随机抽 5000 名学生）只依赖抛硬币，不是任何变量的共同结果，不产生选择偏倚，只损失一点精度。书里还讨论了在零效应下某些选择不改变特定效应度量的情形。

放到你的论文里 · 三个值得想一想的选择

1. 子采样。EdNet 和 Junyi 随机抽 5000 名学生：随机选择，不带来偏倚。

2. 截断到最近 500 次。交互次数受学生投入程度影响，而投入程度和能力、学习增益都有关。截断本身不删学生，但会改变每个学生的历史窗口，长期用户的早期记录被丢掉了。

3. 有后续记录才有奖励。rNLGt 需要“之后在同一技能上的作答”。如果学生做了一道很难的题就放弃这个技能（或放弃整个平台），这一步就没有奖励，被排除在 DR 的样本外。这就是“只分析留下来的人”：选题 A 影响是否留下，能力 U 也影响，条件化留下 → 打开 A → S ← U → Y。下面的实验台模拟这件事。
