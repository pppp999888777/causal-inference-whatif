# 因果推断学习台

Hernán & Robins《Causal Inference: What If》逐章互动学习页面，全书 22 章，每章配可动手的实验台，并对照一篇知识追踪论文讲解。

在线阅读：https://pppp999888777.github.io/causal-inference-whatif/

- `index.html`：目录、阅读路线
- `ch01.html` … `ch22.html`：各章
- `assets/`：共用样式和脚本

原书由作者免费提供：https://miguelhernan.org/whatifbook 。本站讲解为中文转述，实验台数据除注明来自原书的以外均为教学用模拟数据。
