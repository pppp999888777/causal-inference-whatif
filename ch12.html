IP 加权与边际结构模型

第 2 章的 IP 加权在 L 很多的时候怎么做？用一个模型（通常是逻辑回归）估计每个人接受其实际处理的概率，取倒数当权重，再在加权后的伪总体里拟合一个边际结构模型。书从这一章开始用一个真实数据集 NHEFS：戒烟对 10 年体重变化的影响。你论文里的 IPS、SNIPS、权重截断，全是这一章的内容。

这一章的公式
W = 1 / f(A|L) 非稳定权重
SW = f(A) / f(A|L) 稳定权重，均值应 ≈ 1
E[Ya] = β₀ + β₁a 边际结构模型
12.1–12.2

因果问题和用模型估计权重

NHEFS（美国国家健康和营养调查的随访研究）：1566 名吸烟者，1971–75 年基线调查，1982 年随访。处理 A = 期间是否戒烟（403 人戒了，1163 人没戒）；结局 Y = 1971 到 1982 年的体重变化（公斤）。

直接比较：戒烟者平均增重约 4.5 公斤，没戒的约 2.0 公斤，差约 2.5 公斤。但戒烟的人和没戒的人本来就不同：年龄、性别、烟瘾、基线体重、运动习惯都不一样。书里调整了 9 个基线变量 L（性别、年龄、种族、教育、吸烟强度、吸烟年数、日常活动、锻炼、基线体重）。

做法：用逻辑回归拟合 Pr[A=1|L]（连续变量加了平方项），每个人的权重是 1 / Pr[A=ai|Li]。然后在伪总体里比较两组的平均体重变化。书里得到的 IP 加权估计约为 3.4 公斤，比直接比较的 2.5 公斤大。置信区间要用 bootstrap 或稳健方差，因为权重本身是估计出来的。

右边的实验台用模拟的、结构类似 NHEFS 的数据，真实效应设为 3.4 公斤。

稳定权重：同样的答案，更小的波动

非稳定权重 W = 1/f(A|L) 造出的伪总体是原来的两倍大（每人在两个世界各出现一次），权重的平均值约为 2。稳定权重 SW = f(A)/f(A|L) 在分子上乘以处理的边际概率，伪总体和原样本一样大，权重平均值应约为 1。

两个好处：第一，对饱和的边际结构模型，两种权重给出同样的点估计；对非饱和模型（比如连续剂量），稳定权重的置信区间通常更窄。第二，SW 的平均值是一个诊断：如果明显偏离 1，说明处理模型误设或正性接近违反。

放到你的论文里 · IPS、SNIPS 和一个你可以加的诊断

IPS 就是 Horvitz–Thompson 形式的 IP 加权：(1/N) Σ wt rt，wt = π/μ̂。SNIPS 把分母换成权重之和 Σ wt，叫自归一化（Hajek）估计，作用和稳定权重类似：用一点偏差换方差的大幅下降。

诊断：如果 μ̂ 正确且没有截断，Eμ[π/μ] = Σa μ(a)·π(a)/μ(a) = 1，权重的样本平均应接近 1。建议在论文附录里按数据集、按方法报告 mean(wt) 和截断比例。被优化的 Safe-DFKT 策略如果平均权重明显小于 1，就说明它大量选择了日志策略很少选的动作，截断在起作用。

边际结构模型、效应修饰和删失

边际结构模型（MSM）：E[Ya] = β₀ + β₁a。“边际”是说它不以 L 为条件，描述的是整个人群；“结构”是说它是关于潜在结果的模型（因果模型），不是关于观察数据的。在 IP 加权的伪总体里拟合普通回归 Y ~ A，得到的 β₁ 就是因果效应。

处理是连续的（比如吸烟量的变化）时也能用，但 f(A|L) 要用概率密度，通常假设正态。书里提醒：连续处理的 IP 权重对密度模型的设定非常敏感，很容易出现极端权重。

12.5 效应修饰：想知道效应在不同 V 层里是否不同，可以拟合 E[Ya|V] = β₀ + β₁a + β₂Va + β₃V，权重的分子可以用 f(A|V)。V 必须是 L 的一部分。

12.6 删失：NHEFS 里有 63 人 1982 年的体重缺失。用第 8 章的删失权重 1/Pr[C=0|A,L] 乘上处理权重，就同时调整了混杂和选择偏倚。

放到你的论文里 · 你的“处理”是连续的吗

你的动作 k 是离散的（12 到 681 个技能），所以权重用的是概率，不是密度，这比连续处理稳定得多。但技能数一大（Junyi 681 个），每个动作的 μ 都很小，π/μ 很容易非常大，问题和连续处理类似。这也解释了为什么离线评估文献在大动作空间下要用截断、自归一化或结构化的动作嵌入。
