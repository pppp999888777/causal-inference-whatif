随机试验

第 1 章说关联不等于因果。这一章回答：什么条件下关联就等于因果？答案是可交换性。抛硬币分配处理能自动带来它；按某个变量 L 分层抛硬币，则带来条件可交换性，这时要用标准化或 IP 加权把因果效应算出来。

这一章的三个公式
Ya ⫫ A 可交换性
Σl Pr[Y=1|L=l,A=a]·Pr[L=l] 标准化
权重 W = 1 / Pr[A|L] IP 加权
2.1

随机化：让两组人可以互换

设想一个理想的随机试验：每位神抛一枚硬币，正面就移植，反面不移植。没人退出、所有人照分配执行、处理只有一个版本。

这时，被分到移植组的那群人和没分到的那群人，除了硬币以外没有系统差别。如果把两组对调，结果不会变。这叫可交换性：

Ya ⫫ A，对所有 a 潜在结果与实际处理独立

它的意思是 Pr[Ya=1|A=1] = Pr[Ya=1|A=0]：处理组“如果不处理”的风险，和对照组“如果不处理”的风险一样。再加上一致性，就得到最重要的一步：

Pr[Ya=1] = Pr[Ya=1|A=a] = Pr[Y=1|A=a]

左边是因果量，右边是能从数据算的关联量。随机化让关联等于因果。

容易混淆可交换性是 Ya ⫫ A（潜在结果和处理独立），不是 Y ⫫ A（观察结局和处理独立）。后者等于说“没有因果效应”。随机试验里处理有效时，Y 和 A 当然相关。

实验台 2

人越多，抛硬币越管用

一个超总体：重病（L=1）的人占 60%，不管治不治死亡率都是 2/3；轻症死亡率都是 1/4。所以真实因果风险差 = 0。每次随机抽 n 人、抛硬币分组，算关联风险差。

2.2

条件随机化：按病情分层抛不同的硬币

书里的表 2.2 给每位神加了一个变量 L：1 = 病情危重，0 = 不危重。研究者设计了两种方案。方案 1：所有人都按 50% 抛硬币（边际随机化）。方案 2：轻症按 50%，重症按 75% 抛硬币（条件随机化）。

表 2.2 的数据来自方案 2。重症更容易被移植，而重症本来就更可能死，所以边际可交换性不成立：移植组里重症更多。但在 L 的每一层里，分配仍是抛硬币，所以条件可交换性成立：

Ya ⫫ A | L 在 L 的每一层里，两组可以互换

于是每一层内部可以直接比较。轻症层：移植组死亡 1/4，未移植组 1/4；重症层：移植组 6/9 = 2/3，未移植组 2/3。每一层的因果风险比都是 1。可是把两层混在一起直接比（7/13 vs 3/7），就会得出“移植有害”的错误结论。

2.3

标准化：分层算完，再按人群比例加回去

分层结果告诉我们每层的效应，但我们要的是整个人群的 Pr[Ya=1]。做法：在每层里用该层处理为 a 的人的死亡率，再按每层在整个人群里的比例加权平均。

Pr[Ya=1] = Σl Pr[Y=1 | L=l, A=a] · Pr[L=l]

表 2.2 里 Pr[L=1] = 12/20 = 0.6：

Pr[Ya=1=1] = 1/4 × 0.4 + 2/3 × 0.6 = 0.5
Pr[Ya=0=1] = 1/4 × 0.4 + 2/3 × 0.6 = 0.5

因果风险比 = 1，和第 1 章用上帝视角表算出来的一样。注意权重用的是整个人群的 L 分布，不是处理组的。这个公式就是后面的“g 公式”最简单的样子（第 13、21 章）。

2.4

IP 加权：造一个“人人都被处理过”的伪总体

另一种算法：给每个人一个权重，等于他实际得到的处理的概率的倒数，W = 1 / Pr[A=a|L]。

表 2.2 里：轻症不管移不移植权重都是 1/0.5 = 2；重症移植的权重是 1/0.75 = 4/3，重症未移植的是 1/0.25 = 4。

加权后得到一个 40 人的伪总体：原来 20 位神，每位在“移植世界”和“不移植世界”里各出现一次。在伪总体里 L 和 A 不再相关，所以可以直接比较：移植组死亡 10/20，未移植组 10/20，因果风险比还是 1。

直觉：重症里没被移植的人很少（只有 3 位），每一位都要“代表”很多没被观察到的人，所以权重大。

什么时候两种方法给出同一个答案没有模型、L 是离散的时候，标准化和 IP 加权在数学上完全等价（书中技术点 2.3）。有了模型以后，两者依赖的假设不同（第 12、13 章），把两者结合就是双重稳健。
放到你的论文里 · 模拟器的日志就是一个条件随机试验

模拟器里，随机日志策略 μ 根据学生当前历史 ht 选题。这正是“按 L 分层抛硬币”：L = ht，A = 第 t 步选的技能。μ 是你自己写的，所以条件可交换性 Ya ⫫ A | ht 靠设计就成立。

DR 里的权重 wt = π(at|ht) / μ̂(at|ht) 和 2.4 节的 1 / Pr[A|L] 是同一个东西。区别只是目标：书里的目标是“所有人都做 a”，权重是 1[A=a] / Pr[A=a|L]；你的目标是“所有人都按 π 选”，所以分子从 0/1 指示变成了 π 给这个动作的概率。

真实日志就没这么好运

ASSISTments、EdNet 的日志不是你设计的随机试验，是老师和系统按各种理由选的题。μ 不知道，只能从数据估 μ̂，而且学生的某些特征可能没记录。这就从“随机试验”变成了“观察性研究”，是下一章的内容。这也是论文把真实日志上的 DR 只当次要证据的原因。
